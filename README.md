# DemoBlaze E-Commerce Website — Manual Testing Project

## 📌 Overview
This is a self-practice manual testing project performed on **DemoBlaze**, a demo e-commerce web application. The goal was to apply the complete Software Testing Life Cycle (STLC) — from test planning to defect reporting — on a real, publicly available application.

**Application under test:** [DemoBlaze](https://www.demoblaze.com)

## 🎯 Scope of Testing
- Sign-Up & Login functionality
- Home page & category navigation
- Product detail pages
- Cart functionality
- Checkout / Place Order flow
- Contact form

## ✅ What I Did
- Wrote **25+ test cases** covering both positive and negative scenarios
- Designed test scenarios across Sign-Up, Login, Cart, Checkout, and Contact Form modules
- Executed manual test cases and logged Pass/Fail results
- Identified, documented, and classified **6 defects** by severity and priority in a structured defect tracking log
- Applied STLC phases: Requirement Analysis → Test Planning → Test Case Development → Execution → Closure

## 🐞 Key Defects Found
| Defect | Description | Severity |
|---|---|---|
| DEF_01 | Application allows login with invalid credentials | Critical |
| DEF_02 | Cart items don't persist after page refresh | Medium |
| DEF_03 | "Place Order" succeeds even with an empty cart — no validation | Critical |
| DEF_04 | Invalid card number/expiry accepted at checkout without error | High |
| DEF_05 | Contact form accepts invalid email formats without validation | Medium |
| DEF_06 | Contact form allows submission with blank mandatory fields | Medium |
